## `msg_vpn_kafka_sender_queue_binding.add`

Create a queue binding. Skipped if it already exists.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `kafka_sender_name` | string | Yes | - | The name of the Kafka Sender. |
| `queue_name` | string | Yes | - | The name of the Queue. |
| `ack_mode` | string | No | `all` | The number of acks required from the remote Kafka Broker. When "none" messages are delivered at-most-once. When "one" or "all" messages are delivered at-least-once but may be reordered. This must be configured as "all" for an idempotent Kafka Sender, otherwise the Queue Binding will be operationally down. Changing this may briefly interrupt the affected service. (`none`, `one`, `all`) |
| `enabled` | boolean | No | `False` | Enable or disable this queue binding of the Kafka Sender. |
| `partition_consistent_hash` | string | No | `crc` | The hash algorithm to use for consistent partition selection. Changing this may briefly interrupt the affected service. (`crc`, `murmur2`, `fnv1a`) |
| `partition_explicit_number` | integer | No | `0` | The partition number to use for explicit partition selection. Changing this may briefly interrupt the affected service. |
| `partition_random_fallback_enabled` | boolean | No | `True` | Enable or disable fallback to the random partition selection scheme when the consistent partition scheme is being used but no partition key is available for the message. When enabled a random partition will be selected for each unkeyed messages, otherwise some partition will be selected for groups of unkeyed messages. Changing this may briefly interrupt the affected service. |
| `partition_scheme` | string | No | `consistent` | The partitioning scheme used to select a partition of the topic on the Kafka cluster to send messages to. Changing this may briefly interrupt the affected service. (`consistent`, `explicit`, `random`) |
| `remote_key` | string | No | - | The Substitution Expression used to generate the key for each message sent to Kafka. This expression can include fields extracted from the metadata of each individual Solace message as it is taken from the Solace Queue. Changing this may briefly interrupt the affected service. |
| `remote_topic` | string | No | - | The Kafka Topic on the Kafka Cluster to send each message taken from the Solace Queue to. Changing this may briefly interrupt the affected service. |
| `msg_vpn_name` | string | No | - | Message VPN to act on. Defaults to the VPN in the connection config. |
