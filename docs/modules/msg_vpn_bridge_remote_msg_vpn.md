| `bridge_virtual_router` | string | Yes | - | The virtual router of the Bridge. |

| `remote_msg_vpn_location` | string | Yes | - | The location of the remote Message VPN as either an FQDN with port, IP address with port, or virtual router name (starting with "v:"). |
| `remote_msg_vpn_interface` | string | Yes | - | The physical interface on the local Message VPN host for connecting to the remote Message VPN. |
| `client_username` | string | No | - | The Client Username the Bridge uses to login to the remote Message VPN. This per remote Message VPN value overrides the value provided for the Bridge overall. Changing this may briefly interrupt the affected service. |
| `compressed_data_enabled` | boolean | No | `False` | Enable or disable data compression for the remote Message VPN connection. Changing this may briefly interrupt the affected service. |
| `connect_order` | integer | No | `4` | The preference given to incoming connections from remote Message VPN hosts, from 1 (highest priority) to 4 (lowest priority). |
| `egress_flow_window_size` | integer | No | `255` | The number of outstanding guaranteed messages that can be transmitted over the remote Message VPN connection before an acknowledgment is received. Changing this may briefly interrupt the affected service. |
| `enabled` | boolean | No | `False` | Enable or disable the remote Message VPN. |
| `password` | string | No | - | The password for the Client Username. Never returned by the broker, so it is re-sent on every update. Changing this may briefly interrupt the affected service. Sensitive: never echoed in output or docs. |
| `queue_binding` | string | No | - | The queue binding of the Bridge in the remote Message VPN. |
| `tls_enabled` | boolean | No | `False` | Enable or disable encryption (TLS) for the remote Message VPN connection. Changing this may briefly interrupt the affected service. |
| `unidirectional_client_profile` | string | No | `#client-profile` | The Client Profile for the unidirectional Bridge of the remote Message VPN. | `msg_vpn_name` | string | No | - | Message VPN to act on. Defaults to the VPN in the connection config. |
