| `global_caching_heartbeat` | integer | No | `3` | The heartbeat interval, in seconds, used by the Cache Instances to monitor connectivity with the remote Home Cache Clusters. |

| `max_topic_count` | integer | No | `2000000` | The maximum number of topics for each Cache Instance in the Cache Cluster. |
| `msg_lifetime` | integer | No | `0` | The message lifetime, in seconds. If a message remains cached for the duration of its lifetime, the Cache Instance will remove the message. A lifetime of 0 results in the message being retained indefinitely. |
| `new_topic_advertisement_enabled` | boolean | No | `False` | Enable or disable the advertising, onto the message bus, of new topics learned by each Cache Instance in the Cache Cluster. |
| `msg_vpn_name` | string | No | - | Message VPN to act on. Defaults to the VPN in the connection config. |
