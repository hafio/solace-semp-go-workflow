## `msg_vpn_mqtt_session.add`

Create an MQTT session. Skipped if it already exists.

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `mqtt_session_client_id` | string | Yes | - | The Client ID of the MQTT Session, which corresponds to the ClientId provided in the MQTT CONNECT packet. |
| `mqtt_session_virtual_router` | string | Yes | - | The virtual router of the MQTT Session. |
| `enabled` | boolean | No | `False` | Enable or disable the MQTT Session. When disabled, the client is disconnected, new messages matching QoS 0 subscriptions are discarded, and new messages matching QoS 1 subscriptions are stored for future delivery. |
| `owner` | string | No | - | The owner of the MQTT Session. For externally-created sessions this defaults to the Client Username of the connecting client. For management-created sessions this defaults to empty. Changing this may briefly interrupt the affected service. |
| `queue_consumer_ack_propagation_enabled` | boolean | No | `True` | Enable or disable the propagation of consumer acknowledgments (ACKs) received on the active replication Message VPN to the standby replication Message VPN. |
| `queue_dead_msg_queue` | string | No | `#DEAD_MSG_QUEUE` | The name of the Dead Message Queue (DMQ) used by the MQTT Session Queue. |
| `queue_event_bind_count_threshold` | object | No | - |  |
| `queue_event_msg_spool_usage_threshold` | object | No | - |  |
| `queue_event_reject_low_priority_msg_limit_threshold` | object | No | - |  |
| `queue_max_bind_count` | integer | No | `1000` | The maximum number of consumer flows that can bind to the MQTT Session Queue. |
| `queue_max_delivered_unacked_msgs_per_flow` | integer | No | `10000` | The maximum number of messages delivered but not acknowledged per flow for the MQTT Session Queue. |
| `queue_max_msg_size` | integer | No | `10000000` | The maximum message size allowed in the MQTT Session Queue, in bytes (B). |
| `queue_max_msg_spool_usage` | integer | No | `5000` | The maximum message spool usage allowed by the MQTT Session Queue, in megabytes (MB). A value of 0 only allows spooling of the last message received and disables quota checking. |
| `queue_max_redelivery_count` | integer | No | `0` | The maximum number of times the MQTT Session Queue will attempt redelivery of a message prior to it being discarded or moved to the DMQ. A value of 0 means to retry forever. |
| `queue_max_ttl` | integer | No | `0` | The maximum time in seconds a message can stay in the MQTT Session Queue when `queueRespectTtlEnabled` is `"true"`. A message expires when the lesser of the sender assigned time-to-live (TTL) in the message and the `queueMaxTtl` configured for the MQTT Session Queue, is exceeded. A value of 0 disables expiry. |
| `queue_reject_low_priority_msg_enabled` | boolean | No | `False` | Enable or disable the checking of low priority messages against the `queueRejectLowPriorityMsgLimit`. This may only be enabled if `queueRejectMsgToSenderOnDiscardBehavior` does not have a value of `"never"`. |
| `queue_reject_low_priority_msg_limit` | integer | No | `0` | The number of messages of any priority in the MQTT Session Queue above which low priority messages are not admitted but higher priority messages are allowed. |
| `queue_reject_msg_to_sender_on_discard_behavior` | string | No | `when-queue-enabled` | Determines when to return negative acknowledgments (NACKs) to sending clients on message discards. Note that NACKs cause the message to not be delivered to any destination and Transacted Session commits to fail. Changing this may briefly interrupt the affected service. (`never`, `when-queue-enabled`, `always`) |
| `queue_respect_dmq_eligible_enabled` | boolean | No | `False` | Enable or disable the respecting of DMQ Eligible for messages in the MQTT Session Queue. |
| `queue_respect_ttl_enabled` | boolean | No | `False` | Enable or disable the respecting of the time-to-live (TTL) for messages in the MQTT Session Queue. When enabled, expired messages are discarded or moved to the DMQ. |
| `msg_vpn_name` | string | No | - | Message VPN to act on. Defaults to the VPN in the connection config. |
